# Bubble Calculator

A very simple calculator with a rounded, toy-like design: an oval screen, glossy pastel buttons, and a soft click sound.

It's a single HTML file with no build step and no dependencies. Open `calculator.html` in any browser.

## Features

- Add, subtract, multiply and divide, with decimals (× and ÷ are worked out before + and −)
- The screen shows the sum you typed above the answer, and long numbers shrink to fit
- Delete (⌫) and Clear (C) on the side bars
- Buttons squish when pressed, with a click sound you can turn off
- Works with a keyboard

## Keyboard

| Key | Action |
| --- | --- |
| `0`–`9`, `.` | Type a number |
| `+` `-` `*` `/` | Operators |
| `Enter` or `=` | Equals |
| `Backspace` | Delete last digit |
| `Esc` or `C` | Clear |
